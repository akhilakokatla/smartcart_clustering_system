# SmartCart Clustering System - Customer Segmentation

## Overview
E-commerce customer segmentation project to group customers based on purchasing behavior for targeted marketing.

## Problem Statement
SmartCart had all customers treated same. Need to segment them into groups like high-value, budget shoppers etc.

## What I Did
- Data Cleaning: Handled missing values, removed outliers
- EDA: Used heatmaps, countplots, distribution analysis
- Feature Engineering: Created new features, Encoding, StandardScaling
- Found Optimal K: Used Elbow Method + Silhouette Score (Optimal K=4)
- Clustering: Implemented K-Means Clustering
- Cluster Profiling: Analyzed each cluster - e.g. Loyal High-Spenders, Young Budget Buyers etc.

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn (KMeans)

## Results
Segmented customers into 4 distinct clusters, enabling personalized marketing strategy and better customer retention.
